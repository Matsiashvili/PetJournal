# Pet Journal 🐾

## 📌 Project Overview
Pet Journal is an educational Android application designed to help users document their pet’s life through journal entries.  
The app focuses on clean UI, structured navigation, and practical use of Android Jetpack components while providing a simple and user-friendly experience.

This project was developed for learning and academic purposes and is not intended as a commercial product.

## ✨ Features
- Display journal entries using **RecyclerView**
- **Single Activity Architecture** for simplified app structure
- **Navigation Component** with **BottomNavigationView** for smooth fragment navigation
- **Firebase Authentication** for user login and registration
- Local data storage using **SQLite (SQLiteOpenHelper)**
- Remote data synchronization with **Firebase Realtime Database**
- Tabbed navigation using **ViewPager2** and **TabLayoutMediator**
- **Safe Args** for type-safe navigation between fragments

## 🛠️ Tech Stack
- **Language:** Kotlin  
- **Android:** Android Jetpack (Navigation Component, ViewPager2, Safe Args, ViewBinding)  
- **Database:** SQLite (SQLiteOpenHelper), Firebase Realtime Database  
- **Authentication:** Firebase Authentication  
- **UI:** Material Design  
- **Tools:** Android Studio, Git, GitHub
